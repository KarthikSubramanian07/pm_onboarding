# PM Onboarding — Inventory Dashboard

Built with React (frontend) and Node/Express (backend).

**Frontend:** https://pm-onboarding-lemon.vercel.app
**Backend:** https://pm-onboarding.onrender.com

Data is stored in-memory on the backend — no database. Items reset every time the server restarts.

## API

- `GET /inventory` — returns all items
- `POST /inventory` — adds a new item
